# GLITCH//ZERO

Неоновый мобильный рогалик-шутер в браузере: 6 бойцов, 6 режимов, 6 боссов, кейсы, путь трофеев, 81 достижение, 46 предметов, дерево навыков, престиж.

Играть: https://sheixxxx.github.io/glitchzero/

Управление: телефон — джойстик слева, кнопки АТАКА/СУПЕР/РЫВОК справа. ПК — WASD, мышь, пробел, Shift.

Чистый HTML/CSS/JS + Canvas, без сборки. Сохранения в LocalStorage, экспорт/импорт JSON в настройках.
